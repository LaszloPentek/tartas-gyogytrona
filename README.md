# Tartás Gyógytorna Stúdió

Kitalált ügyfél weboldala vizsgamunkához. Az eredeti feladat: `brief-2-gyogytorna.md`.

## Projektállapot
A Git-tároló és a tervezési dokumentáció előkészítve. Weboldal még nem készült.
- `.webprojekt/brief.md`: rendezett munkabrief, a javaslatok külön jelölve.
- `.webprojekt/brief-ellenorzes.md`: ellenőrzés, nyitott részletek.
- `.webprojekt/state.json`: aktuális munkafázis.
- `.webprojekt/skillek.md`: ellenőrzött skillforrások.

A következő lépés a munkabrief egyeztetése, majd a designkoncepciók kidolgozása.
